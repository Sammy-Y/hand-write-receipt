# 手寫發票小幫手

台灣手寫統一發票的開立輔助工具。照著紙本發票的版面直接填寫，自動算好稅額拆分與金額中文大寫，抄到紙本上就好。

純前端、不儲存任何資料、不需要後端。

## 為什麼做這個

停電、機器故障或還沒導入收銀系統時，小商家仍得手寫統一發票。最容易出錯的三件事：

1. **稅額拆分** — 三聯式要拆「銷售額／營業稅 5%／總計」，尾數四捨五入常算錯。
2. **中文大寫** — 跨位補「零」的規則不直覺（10,500 → 壹萬**零**伍佰元整）。
3. **含稅反推** — 客人只講含稅價時要反推未稅金額，且三者相加不能有一元尾差。

網路上的同類計算機欄位都寫死、不能改。這個工具的差異是：**畫面與紙本發票同規格，但每一格都能自己填**——品名、數量、單價、每列金額、備註、銷售額、稅額、總計、應稅／零稅率／免稅、買受人、統編、地址、日期、期別全部可改。自動計算只是輔助帶入，隨時可以手動覆寫。

## 功能

- **三聯式／二聯式**切換，版面依紙本規格呈現（含營業人蓋章區、九格中文大寫欄）
- **雙向計算**：填未稅銷售額往下算，或填含稅總計往上反推，永遠保證 `銷售額 + 稅額 = 總計`
- **稅制切換**：應稅 5%／零稅率／免稅，打勾即重算
- **中文大寫**自動跟隨總計，數字以藍色標示、對齊各自的位數單位，方便照抄
- 品名與備註可換行，長品名不會被截斷
- 一鍵清除重填

金額一律為整數元；稅額尾數依《加值型及非加值型營業稅法施行細則》第 32-1 條四捨五入。

## 開發

需要 Node.js（版本見 `.nvmrc`）。

```bash
npm install
npm run dev        # 開發伺服器
npm run build      # 型別檢查 + production build
npm test           # 單元／元件測試（vitest）
npm run test:e2e   # 端對端測試（Playwright，首次需 npx playwright install chromium）
```

## 專案結構

```
src/
  App.vue                     狀態中樞：發票類型、買受人、品項、金額與所有計算連動
  components/InvoiceSheet.vue 整張發票的版面與欄位（紙本樣式，scoped CSS）
  lib/invoice.ts              純函式：稅額拆分、金額正規化、中文大寫轉換
e2e/invoice.spec.ts           端對端測試
docs/PRD.md                   產品需求
docs/ui-spec.md               版面規格（改 UI 前請先讀）
```

計算邏輯全部收在 `src/lib/invoice.ts`，元件只負責呈現與事件。改動版面前請先看 `docs/ui-spec.md`，裡面記錄了哪些呈現方式是刻意為了貼合紙本、不該「順手優化」。

## 技術棧

Vue 3（`<script setup>` + TypeScript）、Vite、Tailwind CSS 4 + daisyUI 5、Vitest、Playwright。
